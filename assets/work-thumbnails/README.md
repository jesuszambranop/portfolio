# Miniaturas del portfolio

Sube aquí las miniaturas de cada trabajo, separadas por cliente. Las rutas ya están sugeridas en `data/projects.js` mediante `thumbnailHint`.

Ejemplo:

```js
{
  title: "Post 01",
  thumbnail: "assets/work-thumbnails/forestea/post-01.jpg"
}
```

Si `thumbnail` queda vacío, la página muestra un placeholder con el nombre del cliente y el espacio listo para la miniatura.
